# Application

The Next.js website and its complete API server live here. Run application
npm commands from this directory.

Follow the root [README](../README.md) for setup, emulator sign-in, and commands;
see [CONTRIBUTING](../CONTRIBUTING.md) for testing and change conventions.
Local settings are in ignored `.env.local`; production settings are in
`apphosting.yaml`. Source is under `src/`, tests under `tests/`, and development
and maintenance helpers under `scripts/`.
