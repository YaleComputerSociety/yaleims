# Inactive Elo package

Ratings, odds, and research code retained for future work. The application
neither imports nor deploys it. Historical data can be accessed by these
scripts, so review an entry point before running it.

From this directory: `npm ci`, `npm run typecheck`, and
`npm run check:not-imported`. CI runs both checks and prevents the active app
from importing this package. See [CONTRIBUTING](../../CONTRIBUTING.md) before
bringing any behavior back into the application.
